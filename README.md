# BitBox

Editor de video en el navegador para TikTok / Reels. Todo se procesa en el dispositivo; no se sube nada a ningún servidor.

## Publicar en GitHub Pages
1. Crea un repositorio y sube `index.html`.
2. Settings → Pages → Source: rama `main`, carpeta `/ (root)`.
3. Abre `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Uso
- Abre o arrastra un video.
- Recorta arrastrando los tiradores de la línea de tiempo. Espacio = reproducir/pausar.
- Formato, velocidad, filtro, ajustes, texto y volumen en el panel derecho.
- Exportar graba el clip en tiempo real (no cambies de pestaña). Chrome/Edge exportan MP4; otros navegadores pueden exportar WebM.
